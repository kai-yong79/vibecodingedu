# 요구사항

## MVP
- 한국어 홈, Windows 10/11 선택, 공식 설치 안내와 자가 확인
- 한 과정: 준비 → 폴더 열기 → 터미널/OpenCode → 모델/프롬프트 → 결과 확인
- VS Code 모사 인터랙션, 강조, 오클릭 안내, 이전/다음, 키보드 접근
- 프롬프트 복사, 복사 실패 안내, 자기소개 예제 미리보기·HTML 다운로드
- 진도 저장·복원, 초기화 확인, 완료 화면
- 교육용 모사 화면과 실제 작업 완료 자가 확인을 명시적으로 구분

## 제외
자동 설치 EXE, 실제 화면 제어/인식, VS Code 확장, 로그인, DB, 유료 AI, 강사 관리, 영상, 수료증, 다중 과정.
