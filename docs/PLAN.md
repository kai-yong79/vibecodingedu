# AI 바이브코딩 스쿨 개발 계획

2026-10-28. Windows 10/11을 사용하는 코딩 완전 초보자를 위한 온라인 실습 플랫폼.

## 목표와 범위
180분 목표의 발표 가능한 MVP. 핵심은 VS Code와 OpenCode를 모사한 화면에서 강조된 요소를 클릭하는 교육이다. 실제 PC 조작·파일 검증과 시뮬레이션 완료를 구분한다.

## 단계
1. Phase 0 (20분): 폴더 확인, 범위·화면·콘텐츠·저장 구조 설계.
2. Phase 1 (45분): 홈, 설치 안내, 과정 목록, 진행률.
3. Phase 2 (50분): VS Code 모사 화면, 정답 클릭·오클릭 안내, 이전/다음.
4. Phase 3 (35분): OpenCode 안내, 프롬프트 복사, HTML 예제 다운로드·미리보기, 완료.
5. Phase 4 (30분): 빌드·브라우저 검증, 반응형·저장 복원, 배포 준비·발표 문서.

## 화면과 데이터 설계
홈 / 준비하기 / 클릭 실습 / 완료. 좌측 과정 탐색, 중앙 실습 화면, 우측 현재 단계 안내. 모바일에서는 세로로 배치.
콘텐츠는 TypeScript 배열로 관리한다. localStorage에 완료 단계 ID, 현재 단계, 설치 자가 확인, Windows 선택을 저장한다. 저장소 오류는 사용자에게 안내한다.

## 기술
React + TypeScript + Vite + Tailwind CSS. 외부 DB와 유료 API 없음. Vercel 정적 배포 가능. 우선 로컬 검증 후 배포 절차 진행.
