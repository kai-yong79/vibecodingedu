# AI 바이브코딩 스쿨

코딩 완전 초보자가 VS Code·OpenCode 모사 화면을 클릭하며 자기소개 웹페이지 제작 흐름을 배우는 한국어 온라인 교육 MVP입니다.

공개 사이트: https://vibe-school-first-steps.sinjirei.chatgpt.site (방문자 로그인 불필요)

## 가장 편하게 보기 · 다른 호스팅에 올리기

작업공간의 `delivery` 폴더를 사용하세요.

- `offline-preview.html`: 파일을 더블클릭해 브라우저에서 보기. 서버·Node.js 설치가 필요 없는 단일 HTML입니다. 파일로 열면 클립보드·진도 저장은 브라우저 설정에 따라 제한될 수 있습니다.
- `website.zip`: **정적 웹파일을 업로드할 수 있는 호스팅**에 올릴 파일입니다. 압축을 풀면 `index.html`과 `assets`가 나옵니다. 두 항목을 함께 웹 공개 폴더에 올리세요. 사이트 루트와 하위 경로 모두 지원합니다.
- `사용방법.txt`: 위 내용을 정리한 안내입니다.

`website.zip`에는 원본 코드·개발 패키지·Sites 설정·인증 정보가 들어가지 않습니다. 앱 자체에는 ChatGPT 로그인 코드나 외부 API 의존성이 없습니다. 인터넷이 필요한 외부 설치 문서 링크를 제외한 화면 연습은 오프라인으로 사용할 수 있습니다.

수정 후 `npm run share`를 실행하면 빌드와 사용자용 파일 생성을 한 번에 수행합니다. 기존 `.deployment-archive/*.tar.gz`는 Sites 배포 과정의 임시 패키지이며 일반 사용이나 다른 호스팅에는 필요하지 않습니다. 이 로컬 임시 파일을 삭제해도 공개 사이트에는 영향을 주지 않습니다.

## 실행하기
Node.js 20.19+ 또는 22.12+가 필요합니다. 터미널에서 이 폴더로 이동한 뒤:

```sh
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 여세요.

## 빌드
```sh
npm run build
npm run preview
```

배포 파일은 `dist` 폴더에 생성됩니다. Vercel에서는 프로젝트 루트를 이 폴더로 지정하고, 프레임워크 Vite, 빌드 명령 `npm run build`, 출력 폴더 `dist`를 사용하세요. 계정 로그인과 외부 배포가 완료된 뒤 실제 URL을 확인해야 합니다.

호스팅 관리자에게 필요한 계정과 방문자 로그인은 다릅니다. 업로드하는 사람에게 호스팅 계정이 필요할 수 있어도, 공개된 이 사이트를 보는 사람에게는 계정이 필요하지 않습니다. HTTPS 호스팅을 사용하면 프롬프트 복사 기능을 사용할 수 있습니다.

## 구조
- `src/App.tsx`: 홈, 준비, 클릭 교육, 완료
- `src/content.ts`: 단계 데이터, 프롬프트, 독립 실행형 HTML 예제
- `src/index.css`: 반응형 UI
- `docs/`: 계획, 요구사항, 구조, 검증, 로드맵, 발표 시나리오

## 사용 범위
로그인과 API 호출이 없으며 학습 기록은 현재 브라우저의 localStorage에만 저장됩니다. 비공개 모드·저장소 제한·기록 삭제 시 진도가 유지되지 않을 수 있습니다. 초기화는 메뉴에서 확인 후 진행합니다.

실습 화면은 교육용 시뮬레이션입니다. 실제 VS Code를 제어하거나 설치 여부·AI 실행·파일 생성 성공을 검사하지 않습니다. 제공 예제와 실제 AI 생성 결과는 구분됩니다. 예제는 HTML 파일로 다운로드하여 브라우저에서 열 수 있습니다.
